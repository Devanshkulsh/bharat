# Bharat Ayurvedic Medical College Website

Production-ready MVP scaffold for Bharat Ayurvedic Medical College, Hospital & Research Center using React, Vite, TypeScript, Tailwind CSS, React Router, Framer Motion, and Three.js.

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
npm run format
```

## Routes

- `/`
- `/about`
- `/programs`
- `/hospital`, `/research`, `/admissions`, `/gallery`, `/contact`, `/alumni` are scaffolded placeholders.
